# TreeKids 顧客管理システム（児童管理アプリ）

本システムは、**児童発達支援**および**放課後等デイサービス**において、児童（生徒）の基本情報、家族構成、連絡先、アレルギーや特記事項などを一元管理するための業務管理アプリケーションです。

直感的なダッシュボード画面（Bento-Grid UI）を採用し、データベース（Firebase Firestore）を通じて、連携する他のアプリケーション（octopus、書類管理システム、調理・療育記録システム等）とのシームレスなリアルタイム同期を実現しています。

---

## 🌟 主な機能一覧

### 1. 児童情報の詳細・プロファイル管理
* **氏名・ふりがな管理**
  * 「姓」と「名」を個別に管理しつつ、他アプリ連携用のフルネーム（氏名・ふりがな）を裏側で自動生成・同期します。
* **生年月日・学年の自動計算**
  * 生年月日を入力するだけで、日本の学齢基準（4月1日区切り）に基づき、現在の「年齢」と「学年（未就学、年少〜年長、小1〜小6、中1〜中3、高1〜高3、一般）」を自動で計算して表示します。
* **住所・緊急連絡先・保護者勤務先**
  * 自宅住所、緊急連絡先のほか、保護者の勤務先情報（続柄、会社名、電話番号）を複数件管理できます。
* **家族構成**
  * 家族メンバーの氏名、年齢、続柄、連絡先を一覧形式で登録・編集できます。
* **特性・医療・受給者情報**
  * 障がい名、受給者手帳の種類や等級、本人の性格、希望する支援内容、アレルギー情報および特記事項メモを記録できます。

### 2. サービス区分（放課後等デイ / 児童発達支援）の自動判定
* **小学生以上かどうかの自動判定**
  * 生年月日や学年をもとに、**小学生以上（小1〜高3）は「放課後等デイサービス」**、**未就学児（年長以下）は「児童発達支援」**と自動判定してバッジ表示します。
* **他アプリとのステータス共有**
  * 他のアプリからもサービス区分が判別できるよう、データベース上に共通ステータス（`serviceType` 等）を自動保存します。
* **手動での上書き変更**
  * 契約形態や個別事情に合わせて、画面上から手動でサービス区分を変更することも可能です。

### 3. 事業所タグ管理
* **ワンクリック候補ボタン**
  * 「ホーム」「サーチ」「Tree Kids School Home」など、システムに登録されているすべての事業所タグが `+` 候補ボタンとして自動表示され、クリックだけで簡単にタグ付けできます。
* **タグの自由入力追加**
  * 新しい事業所名やグループ名も、テキスト入力ボックスからその場ですぐに追加できます。
* **事業所ごとの絞り込み表示**
  * ヘッダーの事業所タグをクリックするだけで、該当する事業所の児童のみを素早く絞り込み表示できます。

### 4. データのバックアップ・復元・書き出し
* **システム完全バックアップ（JSON形式）**
  * 児童データだけでなく、日報、事業所、操作ログなど、システム内のすべてのデータを1つのファイルに丸ごとまとめてダウンロード保存できます。
* **データの一括復元（JSONインポート）**
  * バックアップファイルを読み込むと、事前に各データの件数（児童〇件、日報〇件など）を確認した上で、データベースへ安全に一括復元できます。
* **Excel確認用の一覧出力（CSV形式）**
  * 全児童の登録情報をExcelやスプレッドシートで直接開ける表形式（文字化け防止のBOM付きCSV）で書き出します。
* **CSVインポート**
  * 外部のCSVファイルから児童データを一括で取り込んで新規登録できます（文字コード自動判定、プレビュー修正機能付き）。

### 5. 操作履歴ログ機能
* 児童の新規登録、情報更新、アーカイブ、削除、インポート、バックアップ復元などの主要な操作が自動的に記録されます。
* 「いつ」「誰が」「どのような操作を行ったか」の履歴を直近100件までいつでも画面上で確認できます。

### 6. 一括操作モード
* 複数の児童にチェックを入れて選択し、一括で「事業所タグの追加・削除」「アーカイブ」「完全削除」を行うことができます。

## 💻 使用技術（技術スタック）

* **画面構築（フロントエンド）**: React 19, Vite, TypeScript
* **デザイン・レイアウト**: Tailwind CSS, Framer Motion（アニメーション）
* **アイコン**: Lucide React
* **データ処理**: PapaParse（CSV変換・パース）
* **データベース・基盤**: Firebase Firestore（リアルタイムDB）, Firebase Authentication（認証）, Firebase Hosting（Webホスティング）

## 🛠️ 開発・更新手順

### 1. 必要なライブラリのインストール
```bash
npm install
```

### 2. パソコンでの動作確認（開発サーバー起動）
```bash
npm run dev
```

### 3. 公開用ファイルのビルド
```bash
npm run build
```

### 4. Webサイトへの公開（Firebase Hostingへのデプロイ）
```bash
npx firebase deploy
```

## 🔒 データの安全性について

* **セキュリティルール**: 認証された関係者のみが安全にデータの閲覧・編集を行えるようアクセス制限を適用しています。
* **他アプリとの完全な互換性**: 児童データが更新されると、連携する他のアプリ側でも即座に最新の氏名やステータスが反映される設計になっています。
