現在のプロジェクト「ryorui-main」に基づいた、縦長画面（モバイル・タブレット）向けのUIレイアウト、スライド操作の仕組み、および具体的なシステム構成をまとめました。

他のアプリ開発でもそのまま指示書として利用できる形式で構成しています。

---

### 1. 画面レイアウト構成（縦長画面・モバイル最適化）

モバイルでの利用を前提とした「App-like」なインターフェース構成です。

*   **全体構造 (`Viewport`)**
    *   `h-screen`（画面の高さ100%）を固定し、`overflow-hidden` でブラウザ全体のスクロールを禁止。
    *   コンテンツ部分のみを個別にスクロールさせることで、ネイティブアプリのような操作感を実現。
*   **固定ヘッダー (`Header`)**
    *   画面上部にタイトルとメニューボタンを固定。
    *   `backdrop-blur`（背景ぼかし）を使用したグラスモーフィズムデザインを適用。
*   **可変サイドバー / ドロワー (`Navigation`)**
    *   **デスクトップ:** 折りたたみ可能なサイドバー（アイコンのみ ↔ テキストあり）。
    *   **モバイル:** 左側からスライドして表示されるドロワー。
*   **メインコンテンツエリア (`Main Content`)**
    *   `overflow-y-auto` で縦方向のみスクロール可能に設定。
    *   `overscroll-behavior-x: none` により、横スワイプ時の「ブラウザの戻る動作」を抑制。
*   **下部ナビゲーション (`Bottom Tabs`)**
    *   モバイル表示時のみ画面下部に固定されるタブバー。主要な機能へのクイックアクセスを提供。

### 2. スライド・ジェスチャー操作の構成

ライブラリに頼らず、標準のタッチイベント (`TouchEvents`) で制御する高レスポンスな構成です。

*   **エッジスワイプ（展開）**
    *   画面左端（約10〜40px）に不可視の「反応ゾーン」を配置。
    *   左から右へのスワイプを検知してドロワーを表示。
*   **メインエリアスワイプ（切り替え）**
    *   コンテンツエリアでの 50px 以上の水平移動を検知。
    *   右スワイプでメニュー展開、左スワイプでメニュー格納。
*   **ドラッグ追従（閉じる操作）**
    *   ドロワーが開いている際、指の動きに合わせてドロワーがリアルタイムに左へ動く（`transform: translateX`）。
    *   一定距離（幅の1/3など）以上引くと閉じ、それ以下なら元の位置に戻る。
*   **スクロール干渉防止**
    *   `touch-action: pan-y` をメインエリアに指定し、縦スクロールを維持しつつ横方向のジェスチャーのみをプログラムで制御。

### 3. 具体的なシステム構成（Tech Stack）

モダンなWeb技術を組み合わせた、高速でスケーラブルな構成です。

| カテゴリ | 具体的な技術 / ツール |
| :--- | :--- |
| **Frontend** | **React 19** + **TypeScript** |
| **Build Tool** | **Vite** (超高速な開発・ビルド) |
| **Styling** | **Tailwind CSS 4** (ユーティリティファースト、高度なカスタマイズ) |
| **Database** | **Cloud Firestore** (リアルタイムNoSQLデータベース) |
| **Auth** | **Firebase Authentication** (Google/メール等の認証) |
| **Hosting** | **Firebase Hosting** (SSL対応、高速配信) |
| **Icons** | **Lucide React** (軽量でモダンなベクターアイコン) |
| **Routing** | **React Router v7** (SPAの画面遷移管理) |
| **Design** | **Glassmorphism** (透明感のあるカードデザイン、高度なCSS変数管理) |
